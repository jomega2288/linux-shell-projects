# Linux Shell Projects

Hands-on Linux projects for cybersecurity learning — Zsh and Bash configuration, commands, redirections, pipes, and the Git/GitHub workflow.

## What's inside

- [`commands_used.md`](commands_used.md) — full command history of Project 7-7: Zsh Configuration & GitHub Integration.
- [`.zshrc`](.zshrc) — my Zsh configuration from that project.

## Project 7-7 — Zsh Configuration & GitHub Integration

A triOS College lab project covering:

1. Setting up a project directory and configuring Zsh (`.zshrc`, autocorrect, autocd)
2. Redirection and pipe exercises (`>`, `|`, `<`, `sort`)
3. Initializing Git, first commit, and renaming the branch to `main`
4. Creating a GitHub Personal Access Token and connecting the local repo
5. Pushing to GitHub

See [`commands_used.md`](commands_used.md) for every command, in order.

## How to use

```bash
git clone https://github.com/jomega2288/linux-shell-projects.git
cd linux-shell-projects
```

Then follow the steps in `commands_used.md` to repeat the exercises.
